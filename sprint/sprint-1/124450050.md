## 2. Keputusan wrangling

Keputusan utama yang saya ambil adalah mempertahankan nilai satuan yang kosong pada data mentah dan tidak langsung mengisinya dengan nilai perkiraan atau asumsi sepihak. 

Berdasarkan pemeriksaan data mentah BPS:
- Berkas `sdg3_3_7_2_v1353.csv`: Kolom `satuan` kosong pada seluruh 69 baris data (100% *missing*).
- Berkas `sdg3_3_7_1_v1394.csv`: Kolom `satuan` terisi lengkap dengan nilai `"Persen"`.

**Alternatif yang ditolak:**
Mengisi satuan secara langsung tanpa memeriksa metadata sumber atau menghapus baris-baris data yang memiliki satuan kosong. Pendekatan tersebut berisiko menghasilkan informasi yang tidak sesuai dengan definisi indikator resmi dan menghilangkan observasi penting.

**Dampak keputusan:**
Pada skema validasi Pandera (`src/validasi/silver.py`), kolom `satuan` ditetapkan bersifat opsional (`nullable=True`). Dengan demikian, jumlah baris data mentah tetap dipertahankan sebanyak 69 baris pada masing-masing indikator tanpa ada data yang terbuang. Satuan akan diverifikasi lebih lanjut melalui metadata resmi BPS sebelum diproses pada tahap berikutnya. Keputusan ini dicatat dalam `log-keputusan.csv` dan didokumentasikan di `docs/data-dictionary.md`.

## 3. Kegagalan dan pelajaran

Salah satu masalah nyata yang ditemukan selama proses validasi adalah ketidaklengkapan metadata satuan pada indikator BPS seri `var1353`. Ketika data diperiksa, seluruh 69 baris memiliki angka pada kolom `nilai`, tetapi kolom `satuan` tidak terisi sama sekali.

Jika data tersebut langsung digabungkan ke pipeline tanpa pemeriksaan, pengguna data dapat salah menginterpretasikan angka capaian indikator tersebut. 

**Pelajaran yang diperoleh:**
Validasi data tidak cukup hanya memeriksa keberadaan kolom dan kelengkapan baris, tetapi juga harus memastikan integritas metadata setiap indikator sesuai dengan definisi dari sumber aslinya. Perbaikan yang telah diterapkan adalah:
1. Membangun skema pemeriksaan otomatis menggunakan Pandera yang memvalidasi tipe data, format periode (tahunan, semester, triwulan, bulanan), dan keunikan kunci komposit.
2. Memberikan fleksibilitas pada kolom yang memang memiliki keterbatasan dari sumber aslinya tanpa mengorbankan kualitas kolom lainnya.

## 4. Bukti

### A. Pemeriksaan Data Mentah BPS

Hasil pemeriksaan terhadap berkas CSV data mentah BPS menunjukkan karakteristik sebagai berikut:

| Ukuran / Indikator | Sebelum Pemeriksaan | Sesudah Pemeriksaan | Perintah Pemeriksaan |
|---|---:|---:|---|
| Baris `var1394` | 69 | 69 | `len(df)` |
| Baris `var1353` | 69 | 69 | `len(df)` |
| Sel kosong `var1394` | 0 | 0 | `df.isna().sum().sum()` |
| Sel kosong `var1353` | 69 | 69 | `df.isna().sum().sum()` |
| Satuan kosong `var1353` | 69 | 69 | `df['satuan'].isna().sum()` |
| Kecocokan SHA-256 Manifest | 13 berkas | 13 berkas cocok | `src.common.manifest.periksa()` |

*Keterangan: Pemeriksaan tidak mengubah berkas mentah. Seluruh 69 baris data mentah dipertahankan keutuhannya.*

Perintah Python untuk menghasilkan pemeriksaan ulang data mentah:

```python
import hashlib
import pandas as pd

file1 = "data/raw/bps/2026-10-20/sdg3_3_7_1_v1394.csv"
file2 = "data/raw/bps/2026-10-20/sdg3_3_7_2_v1353.csv"

df1 = pd.read_csv(file1)
df2 = pd.read_csv(file2)

print("Jumlah baris var1394:", len(df1))
print("Jumlah sel kosong var1394:", df1.isna().sum().sum())

print("Jumlah baris var1353:", len(df2))
print("Jumlah sel kosong var1353:", df2.isna().sum().sum())
print("Satuan kosong var1353:", df2["satuan"].isna().sum())

with open(file1, "rb") as f:
    print("SHA256 var1394:", hashlib.sha256(f.read()).hexdigest())

with open(file2, "rb") as f:
    print("SHA256 var1353:", hashlib.sha256(f.read()).hexdigest())
```
