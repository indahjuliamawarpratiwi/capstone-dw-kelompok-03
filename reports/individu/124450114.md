## 1. Komponen saya

Saya bertanggung jawab pada komponen Penjaga Data & Evaluasi dalam proyek Capstone Data Wrangling. Komponen ini berperan dalam menjaga kualitas data melalui pemeriksaan kelengkapan, konsistensi, validitas, serta kesesuaian data dengan kebutuhan analisis. Hasil evaluasi kualitas data nantinya digunakan sebagai dasar untuk memastikan data hasil wrangling dapat dipercaya dan digunakan oleh anggota tim lainnya.

## 2. Keputusan wrangling

Pada tahap awal proyek, keputusan utama yang saya ambil adalah memastikan dataset yang digunakan telah sesuai dengan manifest sebelum memasuki proses wrangling. Validasi dilakukan dengan menjalankan script pengunduhan dataset dan memeriksa kesesuaian berkas terhadap MANIFEST.csv. Pendekatan ini dipilih dibandingkan menggunakan dataset tanpa pemeriksaan awal karena dapat membantu mengurangi risiko penggunaan berkas yang tidak lengkap atau tidak sesuai. Berdasarkan hasil eksekusi, sebanyak 58 berkas dinyatakan cocok dengan MANIFEST.csv. Keputusan ini menjadi dasar untuk melanjutkan proses pengolahan data pada sprint berikutnya.

## 3. Kegagalan dan pelajaran

Kegagalan yang ditemukan pada tahap awal adalah pipeline belum dapat menjalankan proses ekstraksi data. Ketika menjalankan pipeline.py, proses validasi data berhasil dilakukan, tetapi eksekusi berhenti dengan NotImplementedError pada tahap ekstraksi. Hal ini terjadi karena pembaca untuk setiap format data pada direktori data/raw belum diimplementasikan. Dari kejadian tersebut, saya memahami bahwa keberhasilan pengunduhan dan validasi berkas belum menjamin data dapat langsung digunakan dalam analisis. Setiap tahapan pipeline perlu diuji secara terpisah dan hasilnya perlu didokumentasikan sebagai dasar pengembangan selanjutnya.
