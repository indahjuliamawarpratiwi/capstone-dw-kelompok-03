# Arsip laporan

Folder ini menyimpan laporan yang sudah digantikan oleh keluaran pipeline terbaru. Dokumen di sini
tidak dipakai sebagai bukti final dan dapat memuat angka atau rancangan dari draf sebelumnya.

- `sprint1/persiapan_tahap6.md` — draf persiapan rekonsiliasi sebelum Silver final.
- `sprint1/tahap5_sql_dan_json.md` — draf penyimpanan SQLite sebelum jalur DuckDB dipakai.

Hasil final ada di `reports/tim.md`, `reports/basis-data.md`, `reports/pasangan-rekonsiliasi.md`, dan
`reports/validasi.md`.
